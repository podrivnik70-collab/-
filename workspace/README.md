# Привет, мир!

## Описание
Этот проект содержит простой файл `hello.py`, который выводит "Привет, мир!" в консоль.

## Установка
Для использования этого проекта вам не требуется установка дополнительных зависимостей. Просто скачайте файл `hello.py`.

## Использование
1. Откройте терминал или командную строку.
2. Перейдите в директорию, где находится файл `hello.py`.
3. Выполните команду:
   ```bash
   python hello.py
   ```
4. Вы увидите вывод:
   ```
   Привет, мир!
   ```
