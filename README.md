# Sapphira

Локальный AI-агент для программирования и написания текстов.
Работает без облака (если есть локальные модели) и без Ollama.

## Быстрый старт

1. Двойной клик по `Запуск.bat`.
2. Первый раз bootstrap предложит установить пакеты → «Да».
3. Откроется Sapphira. При первом запуске — wizard выбора моделей.

Всё. Никаких команд, никаких venv.

## Структура

- `bootstrap/`  — первичная установка (окно до GUI)
- `sapphira/`   — основной пакет
  - `core/`     — движок моделей (локальный + облачный)
  - `agents/`   — планировщик, кодер, судьи, оркестратор
  - `features/` — RAG, веб-поиск, документы, база знаний
  - `models/`   — каталог и скачивание GGUF
  - `project/`  — workspace, память, очередь
  - `ui/`       — tkinter (единственное место с UI)
  - `utils/`    — мелкие утилиты
- `models/`     — .gguf файлы (создаётся автоматически)
- `workspace/`  — где Sapphira создаёт проекты
- `data/`       — конфиги и кэш (создаётся автоматически)

## Зависимости

См. `requirements.txt`. `llama-cpp-python` ставится bootstrap'ом с правильным
индексом: CUDA-версия для NVIDIA, иначе CPU.

## Философия

Каждый модуль ~50–300 строк. Одна ответственность. Запускается отдельно
(`python -m sapphira.features.rag`) — так его можно заменить или
самомодернизировать, не боясь сломать остальное.
